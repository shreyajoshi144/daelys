## 3. Definition of done

A story is done when all of these hold:
1. Its acceptance criteria pass in tests against real Postgres and Redis (no SQLite, no mocked database).
2. `ruff`, `ruff format --check` and `mypy` are clean.
3. The project rules still hold: no model call in `rules/`, no writes from `agents/`, only `workers/execute.py`
   writes actions, RLS on any new table.
4. Any new prompt is a versioned file in `agents/prompts/`; any new setting is in `.env.example`.
5. Any decision with a trade-off is recorded in [Technical decisions](../TECHNICAL_DECISIONS.md).
6. UI changes are checked in a real browser.
7. The sprint report shows the real output, and anything not verified is listed as a gap.
